# Specula

맥의 기본 화면 공유에 접속하는 아이폰 앱의 첫 시제품입니다. iOS 17 이상, SwiftUI/UIKit, Network.framework를 사용합니다. 계정 인증의 큰 정수 연산에 BigInt 5.7.0을 사용합니다.

## 실행

1. `MacRemote.xcodeproj`를 Xcode에서 엽니다.
2. Signing & Capabilities의 Bundle Identifier는 `com.ias.specula`입니다. 개발 팀(DEVELOPMENT_TEAM)은 기존 값을 유지합니다. 맥 보조 앱은 `com.ias.specula.display`입니다.
3. 아이폰을 실행 대상으로 선택해 빌드합니다. 로컬 네트워크 접근을 허용합니다.
4. 맥의 시스템 설정 → 일반 → 공유 → 화면 공유를 켭니다.
5. 아이폰에 맥 주소, 맥 사용자 이름(계정의 짧은 이름), 맥 로그인 암호를 입력합니다. 기본 포트는 5900입니다.
6. VNC 공용 암호를 쓰려면 사용자 이름을 비우고 VNC 암호를 입력합니다. 이 경우 맥에서 VNC 뷰어 암호 접속 옵션을 켜야 합니다.

사용자 이름이 있으면 ARD 보안 유형 30으로 맥 계정 로그인을 시도합니다. 이름과 암호는 각각 UTF-8 63바이트 이내이며, 화면 공유에 접근 가능한 맥 계정이어야 합니다. 서버가 유형 30을 제공하지 않으면 오류를 표시하며 VNC 인증으로 자동 전환하지 않습니다. 최신 Apple SRP 인증은 지원하지 않습니다.

사용자 이름을 비우면 기존 VNC 인증을 사용합니다. VNC 공용 암호는 영문·숫자·기호 1~8바이트를 지원합니다. 암호는 디스크에 저장하지 않습니다. 주소, 포트, 사용자 이름만 기기에 저장합니다.

ARD 인증은 DH/MD5/AES로 로그인 정보를 처리하지만 서버의 신원을 검증하거나 이후 화면과 입력을 암호화하지는 않습니다. 기본 VNC도 화면과 입력을 암호화하지 않습니다. 신뢰할 수 있는 로컬 네트워크 또는 VPN에서 시험하세요. 인터넷에 5900 포트를 직접 공개하는 방식은 이 시제품의 사용 범위가 아닙니다.

## 구현 범위

- RFB 3.3 / 3.7 / 3.8 협상, VNC DES challenge-response 인증, ARD 유형 30 맥 계정 인증
- Raw 화면 업데이트 및 화면 크기 변경 수신
- 화면 맞춤 표시, 탭으로 왼쪽 클릭, 길게 눌러 오른쪽 클릭, 한 손가락 드래그, 두 손가락 세로 스크롤
- 영문 화면 키보드, Shift / Command / Backspace / Enter
- 외장 키보드의 US ANSI 위치를 X11 키 기호로 변환해 누름·뗌 전달
- Control-Space 입력기 전환 버튼
- 연결 중 취소, 인증 단계 45초 제한, 백그라운드 이동 시 종료

기본 VNC KeyEvent는 하드웨어 스캔 코드가 아니라 X11 keysym을 보냅니다. 따라서 현재 입력 경로를 ‘물리 키 그대로 전달’로 확정하지 않습니다. 맥 입력기가 한글 조합을 처리하는지는 실제 맥과 아이폰에서 검증해야 합니다. 아이폰 기본 한글 키보드의 조합 문자열을 전송하는 기능은 없습니다. 앱에 있는 영문 키보드는 맥 입력기 동작을 확인하기 위한 시험 도구입니다.

## 한글 실기기 검증

맥에서 텍스트 편집기를 열고 아래를 화면 키보드와 외장 키보드로 각각 확인합니다.

- 영문 상태에서 `abc`, 숫자, Shift 대문자 입력
- 맥 입력기를 두벌식으로 바꾼 뒤 `gksrmf` → `한글`
- `rhk` → `과`, Shift+R 후 `k` → `까`
- 조합 중 Backspace: 받침, 중성, 초성 삭제 순서
- Space / Enter로 조합 확정, 방향키로 이동
- Command+A / C / V와 Control-Space (맥에 지정한 단축키에 따라 다를 수 있음)
- 연결 종료·재연결 후 Shift / Command가 눌린 채 남지 않는지 확인

## 검증 및 한계

`swift test --disable-sandbox`로 핵심 로직을 검사할 수 있습니다. 가상 VNC 서버 테스트는 분할 수신, 인증 응답, 화면 형식 협상, 픽셀 수신과 다음 프레임 요청까지 확인합니다. 실제 맥 화면 공유에서 받은 1600×1200 ZRLE 갱신 24개를 1–1500바이트로 쪼개 같은 클라이언트에 다시 넣습니다. 별도로 알려진 DES 벡터와 키·포인터 패킷을 검증합니다.

시뮬레이터용 앱 빌드와 자동 검사는 실제 맥 화면 공유 호환성, 길게 누르기 우클릭, 한글 입력 성공을 보증하지 않습니다. 사용자가 iPhone Air에서 이 맥으로 테일스케일을 통한 접속과 외장 하드웨어 키보드의 한글 입력 성공을 확인했습니다. 화면 키보드의 전체 한글 검증 항목은 별도로 남아 있습니다.

아직 없는 기능: 확대·이동, 연결 목록, Bonjour 검색, Keychain, Apple SRP 인증, SSH 터널, 클립보드 동기화, 네트워크 변경 시 자동 재연결, 배포용 아이콘·서명. 기본 SetEncodings는 ZRLE, CopyRect, Raw, DesktopSize, LastRect입니다. 커서 의사 인코딩은 켜지 않습니다. 캡처한 세션은 커서를 광고해도 커서 사각형 대신 ZRLE로 포인터를 그렸습니다.

## 큰 인증 키에서의 연결 지연

4096비트 인증 소수의 매번 반복 검증이 Debug 빌드에서 오래 걸릴 수 있습니다. RFC 3526 group 16 소수와 SHA-256 지문이 정확히 일치하면 소수성 재검사를 생략하고, 다른 소수에는 기존 검사를 유지합니다. 피어 공개 키 범위 검사도 유지합니다. 4096비트 키 회귀 검사와 연결 진행 단계 표시를 추가했습니다. 기기 설치에는 최적화한 Release 빌드를 사용합니다. 이 변경은 서버 신원 검증이나 전송 암호화를 추가하지 않습니다.

## 아이폰에서 맥 해상도 변경

`Scripts/build-display-helper.sh`로 맥 보조 앱을 빌드합니다. 결과는 `Build/Specula Display.app`입니다. 번들 ID는 `com.ias.specula.display`입니다. 테일스케일을 켠 상태에서 실행하면 메뉴 막대 아이콘과 5분 동안 유효한 6자리 연결 코드를 표시합니다. 코드를 만들 때마다 화면 가운데에 검은 바탕의 큰 숫자 창이 열리고, 메뉴의 **코드 크게 보기**로 다시 열 수 있습니다. 클릭이나 Esc, 만료, 사용 시 닫힙니다. 테일스케일 CLI는 `/usr/local/bin/tailscale`에 있어야 합니다.

아이폰에서 맥에 접속한 뒤 화면 오른쪽 위의 **⋯ → 맥 해상도**를 열어 코드를 입력합니다. 세로와 가로 모두 이 메뉴만 사용합니다. 맥이 데스크톱에 쓸 수 있다고 보고한 해상도를 모두 표시합니다. 640×480, 720×450 같은 낮은 해상도와 같은 크기의 일반·Retina 모드가 함께 나옵니다. 숫자가 작을수록 글자와 버튼이 크게 보입니다. 일반 모드는 전송량을 줄이고 Retina 모드는 선명도를 우선합니다. 처음에는 1280×720 일반 모드를 권합니다. 이 변경은 실제 맥 화면에도 적용됩니다. 같은 메뉴의 **세로 모드**는 주 디스플레이를 90° 돌리고, 한 번 더 누르면 0°로 되돌립니다. Apple Silicon에서는 비공개 MonitorPanel의 `MPDisplay setOrientation:`으로 돌리고, Intel 맥에서 그 프레임워크를 쓸 수 없을 때만 IOKit 프로브를 사용합니다. 아직 보조 앱에 연결하지 않았으면 연결 코드를 받은 뒤 바로 회전합니다. 이미 연결된 상태에서 회전이 거절되거나 실패하면 해상도 목록을 열지 않고 오류를 보여 줍니다. 회전 후 화면 공유가 세로 크기를 보내면 아이폰은 그 비율로 표시합니다. 연결을 끊으면 원래 각도로 되돌리려 합니다.

첫 변경 직전의 모드를 보관하고, 원격 접속을 종료하면 복원합니다. 이후 여러 번 해상도를 바꿔도 처음 모드로 돌아갑니다. 아이폰 강제 종료나 네트워크 유실로 종료 요청을 못 받으면 마지막 heartbeat로부터 60~65초 후 보조 앱이 복원합니다. 보조 앱의 메뉴에서도 수동 복원할 수 있습니다. 보조 앱을 정상 종료할 때도 복원을 시도하지만 보조 앱 자체의 강제 종료나 맥 충돌까지 복원을 보장하지는 않습니다. 화면 구성 변경이나 모니터 분리로 복원이 실패하면 맥 디스플레이 설정을 확인하세요.

보조 앱은 TCP 5901을 사용하며, 테일스케일 주소 또는 루프백에서 온 연결만 받습니다. 6자리 코드 인증 후 발급한 토큰으로 제어하며 토큰은 아이폰 Keychain에 저장합니다. 코드는 한 번 사용하면 만료되고 분당 오입력 5회로 제한합니다. 보조 앱을 재실행하면 토큰이 바뀌므로 새 코드로 다시 연결해야 합니다. 테일스케일을 통한 암호화된 연결을 전제로 하며 별도 HTTPS는 구현하지 않았습니다. 로그인 시 자동 실행은 설정하지 않습니다.

실제 맥에서 1280×720으로 변경한 뒤 원래 모드로 복원하는 검사를 완료했습니다. 자동 검사에는 원래 모드 보존, heartbeat 만료, 복원 후 늦은 heartbeat 무시, 테일스케일·루프백 주소 제한이 포함됩니다.

## 아이폰 외장 키보드의 보조키

왼쪽 Alt는 원격 맥 Command로, 오른쪽 Alt는 원격 맥 Option으로 보냅니다. Apple 화면 공유 서버에서 Option은 Alt keysym이 아닌 Meta keysym을 사용합니다. 아이폰 시스템이 가로채는 Command 조합은 앱에 전달되지 않을 수 있습니다. 오른쪽 Alt가 없는 경우 화면 키보드의 ⌥ 버튼 또는 ⋯ 메뉴의 Option 켜기를 사용하고, 조합키 입력 후 한 번 더 눌러 끕니다. 연결 종료 시 Option 선택 상태를 초기화합니다.

Option 대괄호 조합은 Apple VNC 서버가 Option 상태를 해제하지 않도록 해당 조합의 문자를 전송합니다. 사용자가 외장 키보드로 마크벡터의 탭 전환 성공을 확인했습니다. 입력 진단 메뉴와 임시 진단 페이지는 제거했습니다.
